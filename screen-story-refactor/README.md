# По ту сторону экрана

Интерактивная браузерная хоррор-история, оформленная как старый рабочий стол.

## Запуск

Открой `Запустить игру.bat` или запусти локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

После этого игра будет доступна по адресу `http://localhost:8000/index.html`.

## Структура

- `index.html` — только HTML-каркас, подключение CSS/JS и базовая разметка рабочего стола.
- `styles/main.css` — весь визуальный стиль: Win95-окна, рабочий стол, чат, почта, эффекты, мини-игра.
- `js/storyData.js` — сценарий игры. Основные сюжетные изменения обычно начинаются здесь.
- `js/storyEngine.js` — движок сценария: читает шаги из `window.STORY` и запускает чат, почту, эффекты и финал.
- `js/desktop.js` — экран включения, иконки рабочего стола, меню "Пуск".
- `js/windows.js` — менеджер окон.
- `js/email.js` — интерактивная почта и вложения.
- `js/folders.js` — содержимое папок "Музыка", "Не трогать", "Секретики".
- `js/minigame.js` — canvas-мини-игра.
- `js/sounds.js` и `js/bgm.js` — звуковые эффекты и фоновая музыка.
- `js/mobile.js` — мобильный viewport, подсказка поворота экрана и best-effort landscape lock.
- `js/tg.js` — необязательная интеграция с Telegram Mini App.
- `assets/story/` — изображения и аудио истории.

## Сценарные шаги

`js/storyData.js` использует массив `window.STORY`. Основные типы:

- `intro` — полноэкранная текстовая подводка.
- `day` — карточка дня.
- `minigame` — ожидание запуска "Онлайн-игры".
- `scene`, `msg`, `narr` — сцены, реплики и внутренний голос в мессенджере.
- `mailadd`, `inbox` — добавление писем и обязательное чтение почты.
- `bgchat` — фоновые сообщения от других контактов.
- `wall`, `music` — смена обоев и фоновой музыки.
- `fx` — эффекты ужаса.
- `end` — финал.

Картинка-скример намеренно оставлена только для финала (`fx` с `kind: "scream"` и `last: true`) и для попытки выключить компьютер после сюжетной блокировки. Раннее напряжение лучше делать письмами, фоновыми чатами, `blackout`, `redtext`, `webcam`, `folderstorm` и обычными репликами.

## Телефон и Telegram

Веб-страница не может гарантированно повернуть физический экран на всех телефонах. `js/mobile.js` пробует `screen.orientation.lock("landscape")` после пользовательского жеста, но в Telegram WebView и на iOS это может быть запрещено. Поэтому игра также показывает короткую подсказку поворота и использует `visualViewport`, чтобы сохранять стабильную высоту и ширину интерфейса при появлении системных панелей.

## Рефакторинг

В исходной версии `index.html` содержал встроенные копии CSS и JS. В этой копии HTML подключает внешние файлы, поэтому источник правок теперь один. Если меняешь механику или сюжет, правь соответствующий файл в `js/`, а не вставки внутри HTML.
